# Did Daymark help you pick up the work?

Try this with one person, their usual assistant and one project they expect to return to. Choose something small enough that trying a different tool will cause little disruption. The question is whether the person spends less effort reconstructing what matters and gets a next step they would actually choose.

This is a field trial a contributor can run privately. The published Daymark agent trials use synthetic tasks. Human outcomes from this exercise have yet to be measured.

## Before changing the routine

Ask the person which part of returning is hard for them. They may want to remember what they promised, see only the decisions that need them, or see their options and choose for themselves. Write down their own description of a good return.

On the next ordinary return, use their existing routine. Ask two short questions after it: “What did you have to explain again?” and “Was there something you expected to see that was missing?” Keep a private tally of corrections and whether they could choose a next step. If switching tools would duplicate a live queue, leave the tasks in the system the person already uses and choose a related follow-up for the trial.

## Try the next return with Daymark

1. Capture the agreed follow-up, who has the move, and any dates the person actually gave. Read it back together. A proposal can wait for a decision.
2. Before the interruption, record where the work stopped and the next unresolved question in a short note. Keep source materials in their usual place.
3. At the next natural return, open a fresh session. Ask the person how they want to see the work today. The agent can offer a scoped shortlist, the ordinary ready list, or deadlines and waits. Let them correct the answer in their own words.
4. Ask what that correction should change. It may concern a fact about the task, this answer, the person's future sessions, or a shared workspace rule. A host needs an identifiable person and a private place to keep a personal choice. Explain what the next session can actually retrieve.
5. On a later return, check the result with the person. Ask whether keeping, changing or dropping the arrangement would help. They can end the trial at either return.

## A private record of each return

| Question | What to write down |
| --- | --- |
| What did the person want to recover? | Their stated aim and whether this was the usual routine or a Daymark return. |
| Could they choose a next step? | Yes, no, or they deliberately chose to defer. Record a missing commitment or blocker if they name one. |
| What did the person have to repeat or correct? | Number of distinct corrections and a short category such as date meaning, wrong audience, missing context or wrong next move. |
| What did the assistant change? | Current answer, task fact, private preference or shared setting. Check the subsequent session against what the person wanted. |
| How did it feel? | Ask what cost more effort, what cost less, and what they would keep. Let them skip the question. |

Compare returns within this person's routine. A rush deadline, a new project member, or a different assistant can explain a change. Record those circumstances and any abandoned return. A faster response that omits a commitment the person cares about is a miss. The person's judgment governs whether to keep using the arrangement.
