Task infrastructure for your application

Tasks on your terms.

Keep deadlines, plans, recurring work, and reminder state in one small Python library. Your application owns the data and the transactions.

Source and quickstartRelease checklist

Start with the library

Requires Python 3.11 or newer. Install from a source checkout; the distribution is daymark-core and the import is daymark.

python -m venv .venv
. .venv/bin/activate
python -m pip install .

Add .[service] for the optional authenticated HTTP API and client. The local CLI and recording worker require no notification provider.

Make timing explicit

A hard deadline, a planned time, an earliest start, and a latest target carry different meanings. Daymark represents local dates and timezone-aware instants separately, with fixed and completion-based recurrence.

Fit the application you have

Use a caller-owned SQLite connection to keep task changes inside your application transaction. Optional service boundaries let standalone clients use the same engine.

Operation identities and expected versions support safe retries and conflict detection. Durable reminder state tracks delivery attempts; your sink handles external delivery and persistent deduplication.

Status

Version 0.1.0 is in initial development. Package registry publication is not yet promised. The default worker records outcomes and sends no notifications.
