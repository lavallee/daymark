# Daymark orientation

2026-11-09. Execution authorized by the commissioning user, who delegates routine
choices. No claim of a separate human design acceptance.

General-purpose Python library for intentional work: tasks, projects, goals,
contexts and durable reminders. Useful for individuals and teams; home management
is one example. No cloud, language model, household schema or hosted dependency.

P0: explicit temporal meanings; workspace-isolated typed records and references;
optimistic versions and operation idempotency; task hierarchy/dependencies;
recurrence occurrence history; leased retryable outbox with stale suppression;
query, event cursor, export/import; embedded caller-owned SQLite transactions;
versioned authenticated HTTP API, Python client and CLI; tested operational path.
P1: portable saved views, descriptions/checklists, provenance, correction/undo.
P2: richer calendar UI, CRDT sync, team invitation UI, complex permission graphs.
These are roadmap, not shipped parity claims.

Acceptance: pure/domain and adversarial integration tests; independent temporal,
transaction and lease review; clean wheel/sdist install; actual application
migration and UI/API readback; durable scheduler health; restore drill; sanitized
public source release. Real notification sending stays with existing ownership
until a replacement is separately proven. No invented times or completions.

Public engine artifacts use synthetic examples. Private integration receipts,
real records, addresses and operational details remain outside this repository.
